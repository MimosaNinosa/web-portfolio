## The problem

Scheduling ran on legacy Excel VBA macros: 45 minutes per run, error-prone, and hard for anyone to maintain.

## What I did

- Led a team of six from framing the problem through to handover.
- Rewrote the scheduling logic in Python. A run went from 45 minutes to about 10 seconds.
- Built a React/Vite dashboard for uploading data, viewing assignments and flagging scheduling conflicts.
- Ran the repository: branching strategy, pull requests and code review.
- Added an AI chatbot to help non-technical staff maintain the code after handover.
